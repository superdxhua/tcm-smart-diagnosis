# 智能中医辅助诊疗 - 桌面版图标说明

## 图标尺寸要求

### Windows (icon.ico)
- **尺寸**: 256x256, 128x128, 64x64, 48x48, 32x32, 16x16
- **格式**: ICO
- **位置**: `electron/icon.ico`

### macOS (icon.icns)
- **尺寸**: 1024x1024 (自动生成其他尺寸)
- **格式**: ICNS
- **位置**: `electron/icon.icns`

### Linux (icon.png)
- **尺寸**: 512x512
- **格式**: PNG
- **位置**: `electron/icon.png`

## 生成图标的方法

### 方法一：使用在线工具（推荐）

1. **准备设计稿**
   - 准备一张 1024x1024 的 PNG 图片
   - 使用我们之前设计的"草药+科技芯片"方案

2. **转换为 ICO (Windows)**
   - 访问: https://www.icoconverter.com/
   - 上传 PNG 图片
   - 下载生成的 ICO 文件
   - 重命名为 `icon.ico`
   - 放置到 `electron/` 目录

3. **转换为 ICNS (macOS)**
   - 访问: https://cloudconvert.com/png-to-icns
   - 上传 PNG 图片
   - 下载生成的 ICNS 文件
   - 重命名为 `icon.icns`
   - 放置到 `electron/` 目录

4. **转换为 PNG (Linux)**
   - 使用原图即可
   - 重命名为 `icon.png`
   - 放置到 `electron/` 目录

### 方法二：使用 ImageMagick（需要安装）

```bash
# 安装 ImageMagick
# macOS: brew install imagemagick
# Ubuntu: sudo apt-get install imagemagick
# Windows: 下载安装包

# 生成 Windows ICO
convert icon.png -define icon:auto-resize=256,128,64,48,32,16 icon.ico

# 生成 macOS ICNS (需要额外工具)
# 使用 iconutil (macOS 自带)
mkdir icon.iconset
sips -z 16 16     icon.png --out icon.iconset/icon_16x16.png
sips -z 32 32     icon.png --out icon.iconset/icon_16x16@2x.png
sips -z 32 32     icon.png --out icon.iconset/icon_32x32.png
sips -z 64 64     icon.png --out icon.iconset/icon_32x32@2x.png
sips -z 128 128   icon.png --out icon.iconset/icon_128x128.png
sips -z 256 256   icon.png --out icon.iconset/icon_128x128@2x.png
sips -z 256 256   icon.png --out icon.iconset/icon_256x256.png
sips -z 512 512   icon.png --out icon.iconset/icon_256x256@2x.png
sips -z 512 512   icon.png --out icon.iconset/icon_512x512.png
iconutil -c icns icon.iconset
```

### 方法三：使用 electron-icon-builder

```bash
# 安装 electron-icon-builder
npm install -g electron-icon-builder

# 从单个 PNG 生成所有平台图标
electron-icon-builder --input=./icon.png --output=./electron --flatten
```

## 临时解决方案（用于测试）

如果暂时没有图标，可以使用以下方法：

1. **使用默认图标**
   - Electron 会使用默认图标
   - 功能正常，但不够专业

2. **使用在线图标**
   - 从免费图标网站下载
   - 例如: https://www.flaticon.com/
   - 搜索: medical, health, chinese medicine

## 图标设计建议

### 设计元素
- **草药**: 使用当归、枸杞、人参等中药材图案
- **科技**: 使用芯片、电路板、波浪线等元素
- **配色**: 主色 #C8102E（中国红），辅色 #764ba2（科技紫）

### 设计风格
- **扁平化**: 简洁现代
- **圆角**: 友好亲和
- **渐变**: 提升质感
