# 数据库迁移指南

## 功能一：用户会话管理（防止多IP登录）

### 迁移步骤

#### 方法一：使用 Supabase 控制台（推荐）

1. 登录 Supabase 控制台
2. 进入你的项目
3. 点击左侧菜单的 "SQL Editor"
4. 点击 "New query" 创建新查询
5. 将 `server/src/storage/database/migrations/create_user_sessions.sql` 文件中的SQL内容复制粘贴到查询编辑器
6. 点击 "Run" 执行SQL

#### 方法二：使用命令行

如果你有 Supabase CLI 工具，可以使用以下命令：

```bash
cd server/src/storage/database/migrations
supabase db execute -f create_user_sessions.sql
```

## 功能说明

### 1. 用户会话管理

**功能**：确保普通用户不能同时在两个不同的IP地址登录程序

**特性**：
- 登录时检查是否有其他IP的活跃会话
- 检测到冲突时拒绝登录
- 记录IP地址、用户代理等信息
- 会话有效期7天
- 管理员不受限制

### 2. 每日签到与积分系统

**功能**：用户每天可以签到领取积分

**特性**：
- 每日签到奖励10积分
- 连续签到7天：额外奖励20积分
- 连续签到30天：额外奖励100积分
- 断签后连续签到天数清零
- 显示签到历史和统计数据

**API接口**：
- POST /api/sign-in - 签到
- GET /api/sign-in/history - 查询签到历史
- GET /api/sign-in/stats - 查询签到统计
- GET /api/points/balance - 查询积分余额

## 注意事项

1. **必须先执行数据库迁移**：在测试新功能之前，必须先创建相关数据表
2. **向后兼容**：如果数据库表未创建，功能会降级处理（不会记录会话）
3. **IP地址获取**：系统会自动从请求头中提取真实IP地址
4. **管理员例外**：管理员账号不受多设备登录限制

## 测试方法

### 用户会话管理

1. 在设备A上登录普通用户账号
2. 在设备B上尝试用同一账号登录
3. 预期结果：设备B登录失败，提示"该账号已在其他设备（IP: xxx）登录"

### 每日签到

1. 登录后进入首页，点击"每日签到"按钮
2. 预期结果：显示签到统计信息，可以点击签到按钮领取积分
3. 再次点击签到按钮，预期结果：提示"今天已经签到过了"

## 常见问题

### Q: 登录失败提示"该账号已在其他设备登录"怎么办？

A: 请先在原设备上退出登录，然后再在新设备上登录。

### Q: 管理员可以在多个设备同时登录吗？

A: 是的，管理员账号不受多设备登录限制。

### Q: 积分有什么用途？

A: 积分可以用于兑换服务套餐等功能（后续实现）。

### Q: 签到奖励规则是什么？

A:
- 每日签到：10积分
- 连续签到7天：额外奖励20积分
- 连续签到30天：额外奖励100积分
- 断签后连续天数清零

### Q: 会话多久过期？

A: 会话有效期为7天，7天后自动过期。用户退出登录时会立即删除会话。
