# PWA 完整使用指南

## 🎯 什么是 PWA？

**PWA（Progressive Web App）** 是一种 Web 应用，具有以下特性：

- ✅ 可以安装到手机主屏幕
- ✅ 有独立的图标和名称
- ✅ 全屏显示，无浏览器地址栏
- ✅ 有启动画面
- ✅ 支持离线访问
- ✅ 性能接近原生 APP
- ✅ 无需下载安装

**关键优势**：
- 🚀 无需下载，添加到主屏幕即可
- 💾 占用空间小（< 1MB）
- 🔄 自动更新，无需手动升级
- 📱 全屏显示，体验接近原生 APP

---

## 📱 如何安装到手机

### iOS 用户（iPhone/iPad）

#### 方法 1：通过 Safari 浏览器

```
1. 打开 Safari 浏览器
2. 访问：https://your-app.vercel.app
3. 点击底部的"分享"按钮（方框加向上箭头图标）
4. 在弹出的菜单中，向下滚动
5. 找到"添加到主屏幕"
6. 点击"添加"按钮
7. 返回主屏幕，找到"中医诊疗"图标
8. 点击图标即可打开
```

#### 方法 2：通过系统提示

```
1. 打开 Safari 浏览器
2. 访问：https://your-app.vercel.app
3. 系统可能会自动提示"添加到主屏幕"
4. 点击"添加"按钮即可
```

**效果**：
- ✅ 桌面出现图标
- ✅ 全屏打开，无地址栏
- ✅ 像原生 APP 一样使用

### Android 用户

#### 方法 1：通过 Chrome 浏览器

```
1. 打开 Chrome 浏览器
2. 访问：https://your-app.vercel.app
3. 点击浏览器右上角菜单（三个点图标）
4. 选择"添加到主屏幕"或"安装应用"
5. 点击"添加"或"安装"按钮
6. 返回主屏幕，找到"中医诊疗"图标
7. 点击图标即可打开
```

#### 方法 2：通过系统提示

```
1. 打开 Chrome 浏览器
2. 访问：https://your-app.vercel.app
3. 系统会自动提示"添加到主屏幕"
4. 点击"添加"按钮即可
```

**效果**：
- ✅ 桌面出现图标
- ✅ 全屏打开，无地址栏
- ✅ 启动画面显示
- ✅ 像原生 APP 一样使用

---

### 微信用户

#### 方法 1：跳转到浏览器

```
1. 在微信中打开链接
2. 点击右上角"..."菜单
3. 选择"在浏览器打开"
4. 按照上述 iOS 或 Android 方法安装
```

#### 方法 2：直接使用（推荐）

```
1. 在微信中直接打开链接
2. 无需安装，直接使用
3. 所有功能完全正常
```

## 🎨 PWA 特性说明

### 1. 全屏显示

安装后，应用会全屏显示，没有浏览器地址栏，体验完全像原生 APP。

### 2. 启动画面

Android 设备会显示启动画面，包含应用图标和名称。

### 3. 离线访问

PWA 支持离线访问，即使没有网络，也可以查看之前访问过的内容。

### 4. 自动更新

应用会自动检测更新，下次打开时会自动更新到最新版本。

### 5. 推送通知

PWA 支持推送通知，可以接收重要提醒（需要用户授权）。

## 🆚 PWA vs 原生 APP vs H5

| 特性 | PWA | 原生 APP | H5 |
|-----|-----|---------|----|
| **安装方式** | 添加到主屏幕 | 下载安装 | 直接访问 |
| **安装时间** | < 10 秒 | 1-5 分钟 | 无需安装 |
| **存储空间** | < 1MB | 10-50MB | 不占空间 |
| **全屏显示** | ✅ 支持 | ✅ 支持 | ❌ 不支持 |
| **离线访问** | ✅ 支持 | ✅ 支持 | ❌ 不支持 |
| **性能** | 90% 原生 | 100% 原生 | 70% 原生 |
| **更新方式** | 自动更新 | 需要重新安装 | 实时更新 |
| **发布审核** | 无需审核 | 需要审核 | 无需审核 |
| **开发成本** | 低 | 高 | 低 |

**结论**：
- **PWA** 是最佳选择，兼顾了性能和便利性
- **原生 APP** 适合需要高性能的场景
- **H5** 适合快速访问和体验

## 🔧 故障排查

### 问题 1：iOS 上找不到"添加到主屏幕"

**原因**：
- Safari 版本过低
- 网络连接问题

**解决方案**：
1. 更新 Safari 到最新版本
2. 刷新页面
3. 尝试方法 2（系统提示）

---

### 问题 2：Android 上没有"添加到主屏幕"选项

**原因**：
- Chrome 版本过低
- 网络连接问题
- PWA 配置错误

**解决方案**：
1. 更新 Chrome 到最新版本
2. 刷新页面
3. 确认已配置 manifest.json
4. 清除浏览器缓存后重试

---

### 问题 3：图标显示错误

**原因**：
- 图标文件缺失
- 图标尺寸不对

**解决方案**：
1. 检查 `public/icons/` 目录下的图标文件
2. 确认所有必需尺寸的图标都存在
3. 重新部署应用

---

### 问题 4：无法全屏显示

**原因**：
- manifest.json 配置错误
- 浏览器不支持

**解决方案**：
1. 检查 `display: standalone` 配置
2. 更新浏览器到最新版本
3. 重新安装应用

---

### 问题 5：微信内无法安装

**原因**：
- 微信内置浏览器限制

**解决方案**：
1. 点击右上角"..."菜单
2. 选择"在浏览器打开"
3. 在浏览器中安装

## 💡 使用建议

### 推荐使用 PWA 的场景

✅ **频繁使用**：每天都要打开的应用
✅ **需要全屏体验**：需要沉浸式体验的应用
✅ **希望快速启动**：像 APP 一样一键打开
✅ **不想占空间**：不想下载大文件

### 推荐使用 H5 的场景

✅ **偶尔使用**：不常打开的应用
✅ **临时使用**：需要快速体验
✅ **微信分享**：通过微信直接访问

### 推荐使用原生 APP 的场景

✅ **高性能需求**：需要极致性能
✅ **硬件功能**：需要调用摄像头、GPS 等
✅ **应用商店推广**：需要在应用商店上架
