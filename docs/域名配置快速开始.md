# 域名配置快速开始 - zhongyihskhealth.com

> ⚡ 10 分钟快速配置指南

---

## 📌 必做步骤（按顺序）

### 1️⃣ 域名解析（2 分钟）

登录域名服务商（如阿里云），添加 2 条 CNAME 记录：

```
类型: CNAME
主机记录: @
记录值: cname.vercel-dns.com

类型: CNAME
主机记录: www
记录值: cname.vercel-dns.com
```

---

### 2️⃣ Vercel 绑定域名（2 分钟）

1. 打开 [Vercel Dashboard](https://vercel.com/dashboard)
2. 点击你的项目 → **Settings** → **Domains**
3. 输入 `zhongyihskhealth.com` → 点击 **Add**
4. 等待验证（显示 ✅ `Valid Configuration`）

---

### 3️⃣ 更新环境变量（1 分钟）

在 Vercel 项目中：

1. **Settings** → **Environment Variables**
2. 找到 `PROJECT_DOMAIN`，修改为：
   ```
   https://zhongyihskhealth.com
   ```
3. 点击 **Save**
4. 点击 **Redeploy** 重新部署

---

### 4️⃣ 微信小程序配置（3 分钟）

1. 登录 [微信公众平台](https://mp.weixin.qq.com/)
2. **开发** → **开发管理** → **开发设置** → **服务器域名**
3. 添加以下域名：

```
request 合法域名: https://zhongyihskhealth.com
uploadFile 合法域名: https://zhongyihskhealth.com
downloadFile 合法域名: https://zhongyihskhealth.com
webview（业务域名）: https://zhongyihskhealth.com
```

4. 点击 **保存**

---

## 🆘 遇到问题？

### DNS 解析未生效？
→ 等待 10-30 分钟，或刷新本地 DNS：
```bash
# Mac/Linux
sudo dscacheutil -flushcache

# Windows
ipconfig /flushdns
```

### 小程序请求失败？
→ 检查微信小程序后台域名配置，确保已保存并等待生效

### SSL 证书错误？
→ Vercel 会自动配置，无需手动操作。如果超过 1 小时未生效，在 Vercel 控制台重新添加域名

### 微信中无法打开？
→ 确认已配置业务域名（webview），检查网站是否被微信拦截
