## 🔧 你需要完成的配置（按顺序）

### 第 1 步：域名解析（约 2 分钟）
在你的域名服务商（阿里云/腾讯云等）添加 DNS 记录：

```
类型: CNAME
主机记录: @
记录值: cname.vercel-dns.com

类型: CNAME
主机记录: www
记录值: cname.vercel-dns.com
```

### 第 2 步：Vercel 绑定域名（约 2 分钟）
1. 打开 [Vercel Dashboard](https://vercel.com/dashboard)
2. 进入你的项目 → **Settings** → **Domains**
3. 添加域名：`zhongyihskhealth.com` 和 `www.zhongyihskhealth.com`
4. 等待验证完成（显示 ✅ `Valid Configuration`）

### 第 3 步：更新 Vercel 环境变量（约 1 分钟）
1. 在 Vercel 项目中，进入 **Settings** → **Environment Variables**
2. 找到 `PROJECT_DOMAIN`，修改为：`https://zhongyihskhealth.com`
3. 点击 **Save**
4. 点击 **Redeploy** 重新部署

### 第 4 步：微信小程序后台配置（约 3 分钟）
1. 登录 [微信公众平台](https://mp.weixin.qq.com/)
2. **开发** → **开发管理** → **开发设置** → **服务器域名**
3. 添加以下域名：

```
request 合法域名: https://zhongyihskhealth.com
uploadFile 合法域名: https://zhongyihskhealth.com
downloadFile 合法域名: https://zhongyihskhealth.com
webview（业务域名）: https://zhongyihskhealth.com
```

4. 点击 **保存**
5. webview（业务域名）需要进行域名所有权验证（见详细文档）

### 第 5 步：验证测试（约 2 分钟）
按照以下顺序测试：

1. **浏览器访问**
   ```
   访问: https://zhongyihskhealth.com
   预期: 页面正常加载
   ```

2. **API 测试**
   ```
   访问: https://zhongyihskhealth.com/api/members
   预期: 返回 JSON 数据
   ```

3. **小程序测试**
   ```
   在微信开发者工具中:
   1. 清除缓存
   2. 重新编译
   3. 测试获取对象列表
   预期: 请求成功
   ```

4. **微信转发测试**
   ```
   在微信中:
   1. 打开 https://zhongyihskhealth.com
   2. 尝试分享给好友
   预期: 页面正常显示，分享功能正常
   ```

- API 端点是否可访问
