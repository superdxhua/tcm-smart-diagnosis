## 💡 注意事项

1. **审核周期**：微信小程序审核通常需要 1-7 个工作日
2. **资质要求**：医疗类小程序可能需要相关医疗资质
3. **内容合规**：确保所有内容符合微信平台规范
4. **隐私保护**：配置用户隐私保护指引
5. **免责声明**：在小程序中添加医疗免责声明

## 🚀 快速上线命令参考

```bash
# 1. 编译小程序
pnpm build:weapp

# 2. 在微信开发者工具中：
#    - 导入 dist 目录
#    - 填入正式 AppID
#    - 点击"预览"测试
#    - 点击"上传"提交代码

# 3. 在微信公众后台：
#    - 完善小程序信息
#    - 配置服务器域名
#    - 提交审核
#    - 审核通过后发布
```
