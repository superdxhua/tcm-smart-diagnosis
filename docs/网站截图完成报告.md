### 任务 1：下载域名证书

**步骤**：

1. 登录阿里云：https://www.aliyun.com
2. 进入"域名管理"
3. 找到你购买的域名
4. 点击"管理"
5. 找到"域名证书"
6. 点击"下载"
7. 保存为：`域名证书_域名.com.pdf`

**用途**：备案时需要上传

---

### 任务 2：配置 DNS 解析

**目标**：将域名指向 Vercel

**步骤**：

#### 步骤 1：获取 Vercel 的 CNAME 记录

1. 登录 Vercel：https://vercel.com/dashboard
2. 进入你的项目
3. 点击"Settings" → "Domains"
4. 点击"Add Domain"
5. 输入你的域名（如 `yiyaojiankang.com`）
6. 获取 CNAME 目标值：`cname.vercel-dns.com`

#### 步骤 2：在阿里云添加 DNS 记录

1. 登录阿里云
2. 进入"域名管理"
3. 找到你的域名
4. 点击"管理"
5. 点击"DNS 解析"
6. 点击"添加记录"
7. 添加以下两条记录：

**记录 1：**
- 记录类型：`CNAME`
- 主机记录：`@`
- 记录值：`cname.vercel-dns.com`
- TTL：`10分钟`

**记录 2：**
- 记录类型：`CNAME`
- 主机记录：`www`
- 记录值：`cname.vercel-dns.com`
- TTL：`10分钟`

8. 点击"确定"

#### 步骤 3：等待 DNS 生效

- 生效时间：5-30 分钟
- 验证方法：
  ```bash
  # Windows
  nslookup yiyaojiankang.com

  # Mac/Linux
  dig yiyaojiankang.com
  ```

---

### 任务 3：在 Vercel 添加自定义域名

**步骤**：

1. 登录 Vercel：https://vercel.com/dashboard
2. 进入你的项目
3. 点击"Settings" → "Domains"
4. 点击"Add Domain"
5. 输入你的域名（如 `yiyaojiankang.com`）
6. 点击"Add"
7. 等待 Vercel 验证 DNS 记录（1-5 分钟）
8. 验证成功后，Vercel 自动配置 SSL 证书
9. 等待 SSL 证书生成（5-10 分钟）

**验证成功标志**：
- 域名状态显示为"Valid Configuration"
- SSL 证书状态显示为"Valid"
