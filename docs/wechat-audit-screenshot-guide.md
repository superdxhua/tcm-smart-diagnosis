## 审核要求概述

### 为什么需要截图？

微信小程序审核时需要提交页面截图，用于：
- 审核人员了解小程序功能
- 验证小程序是否符合审核规范
- 确认小程序页面内容合规

### 截图数量要求

- **最少**：3 张
- **最多**：10 张
- **建议**：提供 5-8 张主要页面截图

## 截图规范要求

### 图片格式

- ✅ **推荐**：PNG 格式（清晰度高）
- ✅ **可选**：JPG 格式（文件较小）
- ❌ **禁止**：BMP、GIF 等其他格式

### 图片尺寸

- **宽度**：建议 750px 或以上
- **高度**：建议 1334px（iPhone 6/7/8 比例）
- **比例**：保持原始屏幕比例，不要拉伸

### 文件大小

- **单张图片**：不超过 2MB
- **所有图片总和**：不超过 10MB

### 内容要求

#### ✅ 必须包含的内容

1. **完整的页面内容**
   - 显示完整的页面布局
   - 不要截取部分区域

2. **清晰的信息展示**
   - 文字清晰可读
   - 图标和按钮清晰可见

3. **真实的页面状态**
   - 显示真实的示例数据
   - 不要使用空白页面

4. **合规的内容**
   - 不含违规信息
   - 符合微信审核规范

#### ❌ 禁止的内容

1. **违规内容**
   - 色情、暴力、赌博等内容
   - 虚假宣传、医疗保证

2. **空白或加载中页面**
   - 不包含数据的页面
   - Loading 状态

3. **模糊不清的图片**
   - 截图模糊
   - 压缩过度

4. **拼图或水印**
   - 多张截图拼成一张
   - 添加个人水印或 Logo

## 如何生成截图

### 方法一：开发者工具截图（推荐）

#### 步骤

1. **打开开发者工具**
   ```bash
   # 启动开发服务器
   coze dev
   ```

2. **打开开发者工具**
   - 运行 `pnpm preview:weapp` 生成预览二维码
   - 用微信扫码预览
   - 打开微信开发者工具

3. **截图页面**
   - 在开发者工具中打开需要截图的页面
   - 点击工具栏的「截图」按钮
   - 保存截图

#### 优点
- ✅ 真实的预览环境
- ✅ 界面清晰
- ✅ 方便快捷

### 方法二：手机截图（最真实）

#### 步骤

1. **生成预览二维码**
   ```bash
   pnpm preview:weapp
   ```

2. **扫码预览**
   - 用微信扫码预览
   - 在手机上打开小程序

3. **截图页面**
   - 使用手机截图功能
   - 依次截图各个页面

4. **提取截图**
   - 从手机相册导出截图
   - 传输到电脑

#### 优点
- ✅ 最真实的显示效果
- ✅ 审核人员更容易接受

### 方法三：H5 版截图（备用）

#### 步骤

1. **启动 H5 版**
   ```bash
   pnpm dev:web
   ```

2. **浏览器访问**
   - 打开浏览器访问 `http://localhost:5000`
   - 使用浏览器截图工具

3. **调整样式**
   - 注意 H5 版和小程序版可能有差异
   - 确保截图反映真实小程序效果

#### 优点
- ✅ 不需要手机
- ✅ 截图质量高

## 注意事项

### 截图前准备

1. **准备测试数据**
   - 创建示例患者
   - 创建示例病历
   - 创建示例处方

2. **检查页面内容**
   - 确保所有页面都有数据
   - 检查是否有空白页
   - 确认文字清晰可读

3. **检查合规性**
   - 不含违规医疗信息
   - 不含虚假宣传
   - 不含敏感内容

### 截图时注意

1. **使用真实环境**
   - 使用预览环境或真实环境
   - 不要使用开发环境的调试界面

2. **保持一致性**
   - 所有截图使用相同的截图方式
   - 保持相同的图片尺寸和比例

3. **按顺序命名**
   - 建议命名：`1-首页.png`、`2-登录页.png` 等
   - 方便上传和审核

### 上传时注意

1. **按顺序上传**
   - 从首页开始
   - 按照功能流程上传

2. **填写说明**
   - 为每张截图填写简要说明
   - 说明页面功能

3. **检查格式**
   - 确认图片格式正确（PNG/JPG）
   - 确认图片大小符合要求

## 常见问题

### Q1: 截图需要包含导航栏吗？

**A**: ✅ 需要。截图应包含完整的页面，包括导航栏。

### Q2: 可以使用 H5 版截图吗？

**A**: ⚠️ 可以但不推荐。建议使用小程序预览版截图，更真实。

### Q3: 截图需要真实数据吗？

**A**: ✅ 需要。建议使用真实的示例数据，不要使用空白页面。

### Q4: 截图可以后期处理吗？

**A**: ❌ 不推荐。应使用原始截图，不要后期编辑。

### Q5: 截图数量有要求吗？

**A**: ✅ 有。最少 3 张，最多 10 张，建议 5-8 张。

### Q6: 截图格式有要求吗？

**A**: ✅ 有。推荐 PNG 格式，JPG 也可以，禁止其他格式。

### Q7: 截图大小有限制吗？

**A**: ✅ 有。单张不超过 2MB，总和不超 10MB。

### Q8: 截图顺序重要吗？

**A**: ✅ 重要。建议按照用户使用流程上传。

## 截图上传流程

### 微信公众平台上传步骤

1. **登录微信公众平台**
   - 访问 [https://mp.weixin.qq.com/](https://mp.weixin.qq.com/)

2. **进入小程序管理**
   - 点击「小程序」
   - 选择你的小程序

3. **进入版本管理**
   - 点击「版本管理」
   - 点击「提交审核」

4. **填写审核信息**
   - 填写版本信息
   - 填写功能描述

5. **上传截图**
   - 点击「上传截图」
   - 选择准备好的截图
   - 按顺序上传

6. **提交审核**
   - 确认信息无误
   - 点击「提交审核」
