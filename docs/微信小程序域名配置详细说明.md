## 📱 配置位置

**路径：**
1. 登录 [微信公众平台](https://mp.weixin.qq.com/)

## 🔧 域名所有权验证（重要）

配置 webview（业务域名）时，需要进行域名所有权验证：

### 验证步骤

**方式 1：文件验证（推荐）**

1. 在你的项目根目录创建验证文件：
   ```bash
   # 文件名由微信提供，格式类似：
   # MP_verify_xxxxxx.txt
   ```

2. 将文件内容（微信提供的验证字符串）写入文件

3. 确保文件可通过以下 URL 访问：
   ```
   https://zhongyihskhealth.com/MP_verify_xxxxxx.txt
   ```

4. 在微信小程序后台点击 **验证**

**方式 2：DNS TXT 记录验证**

1. 在域名服务商添加 TXT 记录：
   ```
   类型: TXT
   主机记录: @
   记录值: [微信提供的验证字符串]
   ```

2. 等待 DNS 生效（10-30 分钟）

3. 在微信小程序后台点击 **验证**

## ⚠️ 重要注意事项

### 1. 域名格式要求

✅ **正确格式：**
```
https://zhongyihskhealth.com
```

❌ **错误格式：**
```
http://zhongyihskhealth.com        (必须使用 HTTPS)
https://zhongyihskhealth.com/api   (不能包含路径)
https://zhongyihskhealth.com:3000  (不能包含端口)
zhongyihskhealth.com              (必须包含协议)
```

### 2. 生效时间

- 配置保存后，通常 **5-10 分钟** 生效
- 建议配置后等待 10 分钟再测试

### 3. 测试验证

在配置完成后，建议按以下步骤测试：

**步骤 1：清除小程序缓存**
```
微信开发者工具 → 菜单栏 → 清除缓存 → 清除全部缓存
```

**步骤 2：重新编译**
```
微信开发者工具 → 菜单栏 → 项目 → 重新编译
```

**步骤 3：测试网络请求**
```javascript
// 在小程序控制台执行测试
wx.request({
  url: 'https://zhongyihskhealth.com/api/members',
  method: 'GET',
  success: function(res) {
    console.log('请求成功', res)
  },
  fail: function(err) {
    console.error('请求失败', err)
  }
})
```

**步骤 4：检查报错信息**

如果仍然报错，注意以下常见错误：

| 错误信息 | 原因 | 解决方案 |
|---------|------|---------|
| `url 不在以下合法域名列表中` | 域名未配置或未生效 | 确认配置并等待生效 |
| `request:fail -2 net::ERR_NAME_NOT_RESOLVED` | DNS 解析失败 | 检查域名解析配置 |
| `request:fail SSL error` | SSL 证书问题 | 等待 Vercel 自动配置证书 |
| `request:fail timeout` | 网络超时 | 检查服务器状态或网络 |

## 🔄 配置变更流程

如果以后需要更换域名（如使用 zhongyihskhealth.cn），需要：

### 1. 更新 DNS 解析
```
将旧域名的 CNAME 记录修改为新域名
```

### 2. 更新 Vercel 域名绑定
```
在 Vercel 控制台添加新域名，删除旧域名
```

### 3. 更新环境变量
```
PROJECT_DOMAIN=https://新域名.com
```

### 4. 重新部署
```
在 Vercel 控制台触发重新部署
```

### 5. 更新微信小程序后台域名
```
删除旧域名，添加新域名
```

### 6. 清除缓存并测试
```
小程序清除缓存后重新测试
```

## 💡 常见问题

### Q1: 配置后多久生效？
**A:** 通常 5-10 分钟，建议等待 10 分钟后再测试。

### Q2: 可以配置多个域名吗？
**A:** 可以，但小程序一次只能使用一个域名。如需切换，需修改代码中的域名配置。

### Q3: 配置域名后还需要修改代码吗？
**A:** 不需要。代码中使用的是 `PROJECT_DOMAIN` 环境变量，更新环境变量后重新部署即可。

### Q4: 为什么配置后还是报错？
**A:** 检查以下几点：
1. 域名格式是否正确（https:// 开头）
2. 是否清除了小程序缓存
3. 是否等待了足够时间（5-10 分钟）
4. 查看具体报错信息，针对性排查

### Q5: 可以使用 http 协议吗？
**A:** 不可以。微信小程序强制要求使用 HTTPS 协议。
