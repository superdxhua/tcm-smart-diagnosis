## 微信支付简介

### 支付方式说明

本系统支持两种微信支付方式：

1. **NATIVE 支付（扫码支付）**
   - 适用于：PC 端、H5 端
   - 用户扫描二维码完成支付
   - 需要管理员提供**收款二维码**（由微信支付自动生成）

2. **JSAPI 支付（小程序支付）**
   - 适用于：微信小程序
   - 用户在小程序内直接调起微信支付
   - 需要**用户 openId**

### 收款码 vs 商户号

- **收款码**：个人微信收款码（不支持系统集成）
- **商户号**：微信支付商户号（支持系统集成）

⚠️ **重要**：本系统使用的是微信支付商户号接口，**不能使用个人微信收款码**。

## 准备工作

### 1. 注册微信支付商户号

1. 访问 [微信支付商户平台](https://pay.weixin.qq.com/)
2. 注册并登录
3. 完成企业认证（需要营业执照）
4. 提交资料审核（通常 1-3 个工作日）

### 2. 关联小程序

1. 登录微信支付商户平台
2. 进入【产品中心】→【AppID 账号管理】
3. 关联你的小程序 AppID
4. 确认授权

### 3. 开通支付产品

1. 进入【产品中心】
2. 开通以下产品：
   - **Native 支付**（扫码支付）
   - **JSAPI 支付**（小程序支付）

## 获取微信支付参数

### 需要获取的参数

| 参数名称 | 参数说明 | 获取位置 |
|---------|---------|---------|
| `WECHAT_PAY_APP_ID` | 小程序 AppID | 微信公众平台 |
| `WECHAT_PAY_MCH_ID` | 微信支付商户号 | 微信支付商户平台 |
| `WECHAT_PAY_API_KEY` | API 密钥 | 微信支付商户平台 |
| `WECHAT_PAY_NOTIFY_URL` | 支付回调地址 | 自己的服务器域名 |
| `WECHAT_PAY_CERT_PATH` | 商户证书路径 | 微信支付商户平台下载 |
| `WECHAT_PAY_CERT_PASSWORD` | 证书密码 | 证书默认为商户号 |

### 详细获取步骤

#### 1. 获取小程序 AppID（WECHAT_PAY_APP_ID）

1. 登录 [微信公众平台](https://mp.weixin.qq.com/)
2. 进入【设置】→【开发设置】
3. 复制 `AppID`

#### 2. 获取商户号（WECHAT_PAY_MCH_ID）

1. 登录 [微信支付商户平台](https://pay.weixin.qq.com/)
2. 进入【账户中心】→【商户信息】
3. 复制 `微信支付商户号`

#### 3. 获取 API 密钥（WECHAT_PAY_API_KEY）

1. 登录微信支付商户平台
2. 进入【账户中心】→【API 安全】
3. 点击【设置 API 密钥】
4. 设置一个 32 位的字符串（例如：`abcdefghijklmnopqrstuvwxyz123456`）
5. **重要**：保存好密钥，丢失后无法找回

#### 4. 获取商户证书（WECHAT_PAY_CERT_PATH）

1. 进入【账户中心】→【API 安全】
2. 点击【申请商户 API 证书】
3. 下载证书（apiclient_cert.p12）
4. 将证书文件放到 `server/certificates/` 目录
5. 证书密码默认为商户号

#### 5. 设置支付回调地址（WECHAT_PAY_NOTIFY_URL）

1. 确保你的服务器有公网域名（已备案）
2. 设置回调地址：`https://your-domain.com/api/payment/callback/wechat`
3. 在微信支付商户平台配置

## 配置支付参数

### 方式一：环境变量配置（推荐）

1. 复制 `.env.example` 为 `.env`

```bash
cp .env.example .env
```

2. 编辑 `.env` 文件，填入真实参数

```env
# 微信支付配置
WECHAT_PAY_APP_ID=wx1234567890abcdef
WECHAT_PAY_MCH_ID=1234567890
WECHAT_PAY_API_KEY=your_32_character_api_key_here
WECHAT_PAY_NOTIFY_URL=https://your-domain.com/api/payment/callback/wechat

# 证书路径
WECHAT_PAY_CERT_PATH=./certificates/apiclient_cert.p12
WECHAT_PAY_CERT_PASSWORD=1234567890

# 支付接口地址（先使用沙箱环境测试）
WECHAT_PAY_API_URL=https://api.mch.weixin.qq.com/sandboxnew
```

### 方式二：代码直接配置

编辑 `server/src/config/wechat-pay.config.ts`：

```typescript
export const wechatPayConfig = {
  appId: 'wx1234567890abcdef',
  mchId: '1234567890',
  apiKey: 'your_32_character_api_key_here',
  certPath: './certificates/apiclient_cert.p12',
  certPassword: '1234567890',
  notifyUrl: 'https://your-domain.com/api/payment/callback/wechat',
  apiUrl: 'https://api.mch.weixin.qq.com/sandboxnew',
}
```

### 创建证书目录

```bash
mkdir -p server/certificates
# 将下载的证书文件放到此目录
```

## 测试支付功能

### 1. 使用沙箱环境测试

微信支付提供沙箱环境，无需真实资金即可测试：

```env
# 沙箱环境
WECHAT_PAY_API_URL=https://api.mch.weixin.qq.com/sandboxnew
```

沙箱环境特性：
- ✅ 无需真实资金
- ✅ 测试支付流程完整
- ✅ 回调通知正常

### 2. 测试流程

#### 测试扫码支付（PC/H5）

1. 用户选择套餐
2. 后端调用统一下单接口，生成支付二维码
3. 用户扫码支付（沙箱环境使用微信支付沙箱账号）
4. 支付成功后，微信发送回调通知
5. 后端处理回调，更新订单状态

#### 测试小程序支付

1. 用户选择套餐
2. 后端调用统一下单接口，获取 prepayId
3. 前端调起微信支付
4. 用户确认支付
5. 支付成功后，微信发送回调通知
6. 后端处理回调，更新订单状态

### 3. 测试回调通知

测试回调通知需要：
1. 服务器有公网访问
2. 回调地址已配置
3. 可以使用工具模拟回调（如 Postman）

## 上线注意事项

### 1. 切换到正式环境

测试通过后，切换到正式环境：

```env
# 正式环境
WECHAT_PAY_API_URL=https://api.mch.weixin.qq.com
```

### 2. 检查回调地址

- ✅ 必须是 HTTPS 协议
- ✅ 域名必须备案
- ✅ 回调地址可访问
- ✅ 证书有效（如果使用双向认证）

### 3. 服务器要求

- ✅ 服务器需支持 HTTPS
- ✅ 服务器需配置 SSL 证书
- ✅ 确保回调地址 24 小时可访问

### 4. 金额格式

微信支付金额单位为**分**（不是元）：

```typescript
// 10 元 = 1000 分
const amount = 10; // 元
const totalFee = Math.round(amount * 100); // 分
```

## 常见问题

### Q1: 能否使用个人微信收款码？

**A**: ❌ 不能。个人收款码不支持系统集成，必须使用微信支付商户号。

### Q2: 注册微信支付需要什么资料？

**A**:
- 企业营业执照
- 法人身份证
- 银行开户许可证
- 联系方式
- 经营场所照片

### Q3: 开通微信支付需要多长时间？

**A**:
- 资料审核：1-3 个工作日
- 签约：审核通过后立即生效
- 总体：约 3-5 个工作日

### Q4: 支付手续费是多少？

**A**:
- 微信支付标准费率：**0.6%**
- 按每笔交易金额收取
- 例如：100 元订单，手续费 0.6 元

### Q5: 如何查询支付记录？

**A**:
1. 登录微信支付商户平台
2. 进入【交易管理】→【交易订单】
3. 查看所有支付记录

### Q6: 支付回调失败怎么办？

**A**:
1. 检查回调地址是否可访问
2. 检查回调地址是否配置正确
3. 查看服务器日志
4. 检查网络连接

### Q7: 沙箱环境如何支付？

**A**:
1. 登录微信支付商户平台
2. 进入【沙箱管理】
3. 获取沙箱账号和密码
4. 使用沙箱账号扫码支付

### Q8: 证书文件丢失怎么办？

**A**:
1. 登录微信支付商户平台
2. 进入【账户中心】→【API 安全】
3. 重新下载证书
4. 旧证书将失效

### Q9: 支持退款吗？

**A**: ✅ 支持。
- 系统已实现退款功能
- 退款需要使用证书
- 退款手续费不退还

### Q10: 如何查看订单状态？

**A**: 系统提供两种方式：
1. 主动查询：调用订单查询接口
2. 被动接收：支付成功后接收微信回调通知

```
用户选择套餐
```

## 安全建议

1. **保护 API 密钥**
   - 不要将密钥提交到代码仓库
   - 使用环境变量存储
   - 定期更换密钥

2. **验证回调签名**
   - 必须验证微信回调的签名
   - 防止伪造回调

3. **使用 HTTPS**
   - 所有支付相关请求使用 HTTPS
   - 防止数据泄露

4. **记录日志**
   - 记录所有支付请求和响应
   - 便于问题排查

5. **订单幂等性**
   - 确保订单只处理一次
   - 防止重复处理
