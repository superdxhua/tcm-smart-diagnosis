# ICP 备案申请指南

> zhongyihskhealth.com 域名备案流程

---

## 📋 备案前准备

### 1. 确认域名状态

**检查域名是否满足备案条件：**

| 条件 | 要求 | 检查方法 |
|------|------|---------|
| 域名所有者 | 必须是个人或企业 | 域名注册信息 |
| 域名状态 | 正常，未过期 | WHOIS 查询 |
| 域名类型 | 支持中文/英文 | 无特殊限制 |
| 域名持有时间 | 无要求 | 无 |

**检查命令：**
```bash
WHOIS 查询
访问: https://whois.com/
输入: zhongyihskhealth.com
查看: 注册信息、到期时间
```

---

### 2. 准备备案材料

#### 个人备案：

| 材料 | 要求 | 说明 |
|------|------|------|
| **身份证** | 正反面照片 | 清晰、无遮挡、有效期 |
| **手机号** | 实名认证 | 与域名注册信息一致 |
| **邮箱** | 实名认证 | 用于接收备案通知 |
| **域名证书** | 电子版 | 从域名服务商下载 |

#### 企业备案：

| 材料 | 要求 | 说明 |
|------|------|------|
| **营业执照** | 扫描件或照片 | 清晰、盖公章 |
| **法人身份证** | 正反面照片 | 法人代表身份证 |
| **授权书** | 扫描件 | 如非法人亲自办理 |
| **域名证书** | 电子版 | 从域名服务商下载 |
| **网站负责人身份证** | 正反面照片 | 实际负责人身份证 |
| **网站负责人手机号** | 实名认证 | 用于核验 |
| **网站负责人邮箱** | 实名认证 | 用于接收通知 |

## 🔧 备案步骤（以阿里云为例）

### 第 1 步：注册备案服务商账号

1. 访问 [阿里云 ICP 备案系统](https://beian.aliyun.com/)
2. 注册账号（如已有阿里云账号可直接登录）
3. 完成实名认证

**实名认证需要：**
- 个人：身份证信息
- 企业：营业执照 + 法人信息

---

### 第 2 步：备案申请

#### 2.1 填写主体信息

**个人备案：**
```
主体类型: 个人
姓名: [你的姓名]
证件类型: 身份证
证件号码: [身份证号]
手机号: [手机号]（需要接收验证码）
邮箱: [邮箱地址]
```

**企业备案：**
```
主体类型: 企业
单位名称: [公司全称]
统一社会信用代码: [营业执照号码]
证件类型: 营业执照
证件号码: [营业执照号码]
法人姓名: [法人姓名]
法人身份证号: [法人身份证号]
手机号: [公司手机号]
邮箱: [公司邮箱]
```

#### 2.2 填写网站信息

```
网站名称: 中医智能健康管理 / 中医诊疗助手 / 中医健康管理平台
（建议包含"健康"、"医疗"等相关词汇，避免使用"中国"、"中华"等词）

网站首页网址: https://zhongyihskhealth.com

网站服务内容:
- 个人备案: 个人博客 / 个人主页
- 企业备案: 医疗信息 / 健康咨询 / 医疗辅助

网站语言: 中文

前置审批类型: 无

网站内容描述:
基于AI大模型的中医智能诊疗平台，提供智能问诊、经方推荐、健康管理等服务。
（简洁描述网站功能，不超过 200 字）
```

#### 2.3 上传材料

**个人备案上传：**
- 身份证正反面照片
- 域名证书

**企业备案上传：**
- 营业执照扫描件
- 法人身份证正反面
- 域名证书
- 网站负责人身份证正反面
- 授权书（如需要）

---

### 第 3 步：服务器信息

**重要：由于使用 Vercel（海外服务器），需要特殊处理。**

#### 3.1 Vercel 不支持直接备案

**问题：**
- Vercel 是美国服务器，不符合中国备案要求
- 备案需要提供中国大陆的服务器信息

#### 3.2 解决方案：使用国内服务器进行备案

**方案 1：购买阿里云/腾讯云服务器（临时）**

1. 购买一台便宜的云服务器（如阿里云 ECS）
2. 选择配置：1 核 1G，1-2 个月（临时用于备案）
3. 费用：约 100-300 元

**方案 2：使用虚拟主机/共享主机**

1. 购买阿里云/腾讯云虚拟主机
2. 价格更便宜：约 50-100 元/年
3. 备案用途：仅用于备案审核

**方案 3：使用备案服务商推荐的服务器**

1. 部分备案服务商提供免费备案服务器
2. 备案通过后可以迁移到 Vercel
3. 需要咨询客服

#### 3.3 备案时填写的服务器信息

```
服务器提供商: 阿里云 / 腾讯云
服务器所在地: 中国大陆
IP 地址: [云服务器 IP]
备案服务号: [备案服务商提供]
```

### 第 5 步：提交审核

#### 5.1 服务商审核（1-3 个工作日）

**审核内容：**
- 材料是否齐全
- 信息是否正确
- 是否符合备案要求

**审核通过：**
- 进入管局审核阶段

**审核不通过：**
- 根据驳回原因修改
- 重新提交

#### 5.2 管局审核（1-20 个工作日）

**审核时间：**
- 省份不同，审核时间不同
- 一般：5-15 个工作日
- 最快：1-3 个工作日
- 最慢：20 个工作日

**审核通过：**
- 获得备案号
- 备案信息可在工信部网站查询

**审核不通过：**
- 根据驳回原因修改
- 重新提交

---

### 第 6 步：备案通过后的操作

#### 6.1 获得备案号

备案通过后，你会获得：
- 备案号：如 `京ICP备12345678号-1`
- 备案密码：用于后续修改备案信息

#### 6.2 在网站底部显示备案号

在网站底部添加备案信息：

```html
<div class="beian">
  <a href="https://beian.miit.gov.cn/" target="_blank">
    京ICP备12345678号-1
  </a>
</div>
```

**样式建议：**
```css
.beian {
  text-align: center;
  color: #999;
  font-size: 12px;
  margin-top: 20px;
}

.beian a {
  color: #999;
  text-decoration: none;
}

.beian a:hover {
  color: #333;
}
```

#### 6.3 将域名解析改回 Vercel

备案通过后：
1. 登录域名服务商
2. 修改 DNS 解析：改回 Vercel IP
3. 等待 DNS 生效（10-30 分钟）

## ⚠️ 重要注意事项

### 1. 备案期间

- 域名必须指向备案服务器
- 网站必须可以访问
- 网站内容必须符合备案描述
- 网站不能有违规内容

### 2. 备案内容

**网站名称要求：**
- ❌ 不能使用"中国"、"中华"、"国家"等词
- ❌ 不能包含"官方"、"权威"等词
- ❌ 不能包含个人姓名
- ✅ 建议使用描述性的名称

**网站内容要求：**
- ✅ 内容与备案描述一致
- ❌ 不能有违法违规内容
- ❌ 不能有赌博、色情等内容
- ❌ 不能涉及金融、医疗诊疗（非执业）

### 3. 医疗类网站特殊要求

**如果你的网站涉及医疗咨询：**

- ⚠️ 需要提供《互联网医疗保健信息服务许可证》
- ⚠️ 需要提供执业医师资质证明
- ⚠️ 需要明确标注"仅供参考，不作为诊疗依据"

**建议备案类型：**
- 个人备案：个人博客 / 健康知识分享
- 企业备案：健康管理 / 健康咨询（非诊疗）

### 4. 备案变更

**以下情况需要变更备案：**
- 更改网站内容
- 更改网站名称
- 更改主体信息
- 转让域名

## 💡 常见问题

### Q1: 必须购买国内服务器才能备案吗？

**A:**
- ✅ 管局要求备案服务器必须在中国大陆
- ✅ 可以购买便宜的临时服务器（100-300 元）
- ✅ 备案通过后可以改回 Vercel

### Q2: 备案后一定要使用国内服务器吗？

**A:**
- ❌ 不需要
- ✅ 备案后可以将域名解析改回 Vercel
- ✅ 但网站内容必须符合备案描述

### Q3: 个人备案和企业备案有什么区别？

**A:**

| 项目 | 个人备案 | 企业备案 |
|------|---------|---------|
| 所需材料 | 身份证 | 营业执照 + 法人信息 |
| 网站类型 | 个人博客/主页 | 企业官网/服务平台 |
| 可否备案多个域名 | 最多 1 个 | 可备案多个 |
| 网站内容 | 个人性质 | 企业性质 |
| 审核时间 | 相对较快 | 相对较慢 |

### Q4: 备案失败怎么办？

**A:**
- 查看驳回原因
- 根据原因修改材料
- 重新提交
- 可以多次尝试

### Q5: 备案有效期是多久？

**A:**
- 备案永久有效
- 但需要定期审核（每年）
- 网站内容必须符合备案要求
