## 📋 配置清单

### 域名配置
- [ ] 域名 DNS 解析配置（CNAME → Vercel）
- [ ] Vercel 域名绑定
- [ ] SSL 证书自动配置
- [ ] 环境变量更新（PROJECT_DOMAIN）

### ICP 备案
- [ ] 查询域名备案状态
- [ ] 准备备案材料（身份证/营业执照）
- [ ] 下载域名证书
- [ ] 选择备案服务商（阿里云/腾讯云）
- [ ] 购买临时备案服务器（如需要）
- [ ] 提交备案申请
- [ ] 等待服务商审核（1-3 天）
- [ ] 等待管局审核（5-20 天）
- [ ] 获得备案号
- [ ] 在网站底部显示备案号
- [ ] 修改 DNS 解析回 Vercel
