## 🔧 配置步骤

### 步骤 1：域名解析配置（重要）

在你的域名服务商（阿里云、腾讯云等）配置 DNS 解析：

**zhongyihskhealth.com 的 DNS 记录：**

| 记录类型 | 主机记录 | 记录值 | TTL |
|---------|---------|--------|-----|
| CNAME   | @      | cname.vercel-dns.com | 600 |
| CNAME   | www    | cname.vercel-dns.com | 600 |

**说明：**
- `@` 表示根域名（zhongyihskhealth.com）
- `www` 表示 www 子域名（www.zhongyihskhealth.com）
- Vercel 会自动处理 SSL 证书

---

### 步骤 2：Vercel 域名绑定

1. 登录 [Vercel 控制台](https://vercel.com/dashboard)
2. 进入你的项目
3. 点击 **Settings** → **Domains**
4. 添加域名：`zhongyihskhealth.com`
5. 添加域名：`www.zhongyihskhealth.com`
6. Vercel 会自动验证 DNS 配置

**预期状态：**
- 域名状态显示为 ✅ `Valid Configuration`
- SSL 证书自动配置完成

---

### 步骤 3：更新环境变量

在 Vercel 项目中更新环境变量：

1. 进入 **Settings** → **Environment Variables**
2. 更新 `PROJECT_DOMAIN` 变量：
   - **当前值：** `/`（相对路径，仅用于开发）
   - **新值：** `https://zhongyihskhealth.com`（生产域名）

**其他环境变量保持不变。**

---

### 步骤 4：小程序后台域名配置（关键）

登录 [微信公众平台](https://mp.weixin.qq.com/)，配置服务器域名：

**配置路径：**
- 开发 → 开发管理 → 开发设置 → 服务器域名

**需要配置的域名：**

| 域名类型 | 域名地址 | 说明 |
|---------|---------|------|
| request 合法域名 | `https://zhongyihskhealth.com` | HTTPS 请求 |
| uploadFile 合法域名 | `https://zhongyihskhealth.com` | 文件上传 |
| downloadFile 合法域名 | `https://zhonghskhealth.com` | 文件下载 |
| webview（业务域名） | `https://zhongyihskhealth.com` | H5 网页 |
| socket 合法域名 | `https://zhongyihskhealth.com` | WebSocket（如需） |

**注意事项：**
- 必须使用 HTTPS 协议
- 不要包含端口号
- 不要包含路径（如 `/api`）
- 配置后需要等待几分钟生效

---

## 🔍 常见问题排查

### 问题 1：域名解析未生效

**症状：**
- 访问域名显示 `site not found`

**解决方案：**
1. 等待 DNS 传播（通常 10-30 分钟）
2. 检查 DNS 记录是否正确配置
3. 使用 `nslookup` 或 `dig` 命令检查解析

### 问题 2：SSL 证书错误

**症状：**
- 浏览器显示 `证书不安全`

**解决方案：**
1. 在 Vercel 控制台检查 SSL 状态
2. 确保 DNS 记录已指向 `cname.vercel-dns.com`
3. Vercel 会自动配置 Let's Encrypt 证书

### 问题 3：小程序网络请求失败

**症状：**
- 小程序报错 `不在以下 request 合法域名列表中`

**解决方案：**
1. 确认在微信公众平台已配置域名
2. 确认域名使用 HTTPS 协议
3. 等待几分钟后重新测试
4. 清除小程序缓存后重试

### 问题 4：微信中无法打开网页

**症状：**
- 微信中访问显示 `无法访问`

**解决方案：**
1. 确认已配置业务域名（webview）
2. 检查网站是否被微信拦截
3. 使用 [微信域名检测工具](https://mp.weixin.qq.com/debug/cgi-bin/sandbox?t=jsapisign) 检查
