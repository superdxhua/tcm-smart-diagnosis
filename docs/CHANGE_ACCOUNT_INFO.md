# 微信小程序账号信息变更指南

## 📋 查看当前账号状态

### 步骤 1：登录微信公众平台
1. 访问：https://mp.weixin.qq.com
2. 使用原账号密码登录

### 步骤 2：查看账号信息
1. 登录后进入"设置" → "基本设置"
2. 查看"主体信息"部分
3. 记录以下信息：
   - 账号类型（个人/企业/个体工商户）
   - 主体名称（当前药店名称）
   - 主体信息（营业执照号/身份证号）
   - 认证状态（已认证/未认证）

---

## 🔄 场景 1：只想修改小程序名称

### 适用情况
- ✅ 药店名称变了，但主体信息（营业执照）没变
- ✅ 只是想修改小程序的显示名称

### 操作步骤
1. 登录微信公众平台
2. 进入"设置" → "基本设置"
3. 找到"小程序名称"
4. 点击"修改"按钮
5. 输入新的小程序名称
6. 提交修改

### 注意事项
- ⚠️ **小程序名称每年只能修改 2 次**
- ⚠️ 名称长度限制：4-30 个字符
- ⚠️ 不能使用违反规定的词语
- ⚠️ 需要通过审核后生效（通常 1-7 天）

---

## 🔄 场景 2：主体信息变更（药店名称变了）

### 适用情况
- ❌ 药店营业执照名称变了
- ❌ 主体信息（营业执照号）变了
- ❌ 需要更换营业执照

### ⚠️ 重要限制
**微信小程序的主体信息一旦注册，不能直接修改！**

必须通过以下方式解决：

---

## 🛠️ 解决方案

### 方案 1：重新注册小程序（推荐）

#### 步骤 1：注销原小程序（可选）
```bash
1. 登录微信公众平台
2. 进入"设置" → "账号信息"
3. 点击"注销账号"
4. 确认注销（不可逆）
5. 等待审核（通常 1-3 天）
```

**⚠️ 注意事项：**
- ❌ 注销后不可恢复
- ❌ 所有数据会丢失
- ❌ 需要提前备份重要数据

#### 步骤 2：使用新营业执照重新注册
```bash
1. 访问：https://mp.weixin.qq.com
2. 点击"立即注册"
3. 选择"小程序"
4. 选择主体类型：企业/个体工商户
5. 填写新营业执照信息
6. 上传新营业执照照片
7. 填写管理员信息
8. 完成注册
9. 获取新的 AppID
```

#### 步骤 3：迁移数据（如果有重要数据）
```bash
1. 导出原有数据（如用户数据、订单数据）
2. 重新部署小程序到新账号
3. 配置新的 AppID
4. 测试功能
5. 提交审核
```

---

### 方案 2：迁移账号（高级选项）

#### 什么情况可以迁移？
- ✅ 主体信息变更（如企业更名）
- ✅ 主体合并或拆分
- ✅ 主体类型变更

#### 迁移步骤
1. **准备材料**
   - 新主体营业执照
   - 主体变更证明（工商局出具）
   - 迁移申请表

2. **提交申请**
   ```bash
   1. 登录微信公众平台
   2. 进入"设置" → "账号信息"
   3. 点击"主体迁移"
   4. 填写新主体信息
   5. 上传证明材料
   6. 提交申请
   ```

3. **等待审核**
   - 审核时间：7-15 个工作日
   - 可能需要补充材料

4. **完成迁移**
   - 审核通过后，小程序主体信息变更
   - 原小程序保留，但归属权转移

**⚠️ 注意事项：**
- ❌ 个人账号无法迁移到企业账号
- ❌ 迁移需要支付费用（约 300 元）
- ❌ 迁移后不可撤销
- ❌ 需要重新认证（300 元/年）

---

### 方案 3：使用新执照注册，保留原小程序

#### 步骤 1：用新营业执照注册新小程序
```bash
1. 访问：https://mp.weixin.qq.com
2. 注册新的企业小程序
3. 使用新营业执照信息
4. 获取新的 AppID
```

#### 步骤 2：发布新小程序
```bash
1. 部署项目代码到新 AppID
2. 提交审核
3. 审核通过后发布
```

#### 步骤 3：处理原小程序（可选）
```bash
选项 A：继续运营原小程序
  - 两个小程序可以同时存在
  - 用户可以分别使用

选项 B：停止运营原小程序
  - 在原小程序发布停用公告
  - 引导用户迁移到新小程序
  - 后续可以注销原小程序
```

## 📝 具体操作步骤

### 查看当前账号信息
```bash
1. 登录：https://mp.weixin.qq.com
2. 进入"设置" → "基本设置"
3. 查看"主体信息"：
   - 账号类型：个人/企业/个体工商户
   - 主体名称：当前药店名称
   - 主体信息：营业执照号/身份证号
4. 查看"小程序信息"：
   - 小程序名称：当前显示名称
   - 小程序简介：功能介绍
   - 服务类目：选择的行业
```

### 修改小程序名称
```bash
1. 登录微信公众平台
2. 进入"设置" → "基本设置"
3. 找到"小程序名称"
4. 点击"修改"按钮
5. 输入新的小程序名称
6. 点击"提交"
7. 等待审核（1-7 天）
8. 审核通过后生效
```

### 重新注册小程序
```bash
1. 访问：https://mp.weixin.qq.com
2. 点击"立即注册"
3. 选择"小程序"
4. 选择主体类型：
   - 个体工商户（推荐药店）
   - 企业
5. 填写信息：
   - 主体名称：新药店名称
   - 营业执照号：新执照号码
   - 法定代表人：法人姓名
   - 上传新营业执照照片
6. 填写管理员信息：
   - 姓名：管理员姓名
   - 身份证号：管理员身份证
   - 手机号：管理员手机
   - 上传身份证照片
7. 绑定微信（扫码确认）
8. 完成注册
9. 获取新的 AppID
```

### 账号迁移
```bash
1. 准备材料：
   - 新营业执照
   - 主体变更证明（工商局出具）
   - 法定代表人身份证
   - 管理员身份证
   - 主体迁移申请表（下载填写）

2. 提交申请：
   - 登录微信公众平台
   - 进入"设置" → "账号信息"
   - 点击"主体迁移"
   - 填写新主体信息
   - 上传证明材料
   - 填写迁移申请表
   - 提交申请

3. 等待审核：
   - 审核时间：7-15 个工作日
   - 可能需要补充材料
   - 审核结果会通过微信通知

4. 完成迁移：
   - 审核通过后，主体信息变更
   - 原小程序归属权转移
   - 需要重新认证（300 元）
```
